# Mishloach Manot

A C++ console program for gift packages. A package has a sender, a recipient, an address, and products. A gift package extends that model with a gift name, a price, and a size.

The program builds a few packages, prints each one, calculates the price, and prints the average price of the gift packages.

## Stack

- C++
- Visual Studio

## Run

Open `MishloachManot.sln` and run the console project.

## Layout

```text
MishloachManot/
  Address.h, Address.cpp
  Product.h, Product.cpp
  Mishloach.h, Mishloach.cpp
  Gift.h, Gift.cpp
  MishloachManot.cpp
```

Compiler output under `x64/` is ignored.
